# Smart Tab Manager — Chrome Web Store Listing

## Store Description (English)

**🧠 Smart Tab Manager — AI-Powered Tab Organization**

Drowning in tabs? Smart Tab Manager automatically organizes your browser chaos using AI-powered topic detection. Group tabs by content (not just domain), detect duplicates, search across all open tabs, and save sessions — all from a beautiful dark-themed popup.

### ✨ Features

- **🤖 Smart Grouping** — AI categorizes tabs into topics: Dev, Social, News, Video, AI, Shopping, Docs, and more. Groups get emoji labels and color codes.
- **📦 Domain Grouping** — Quick domain-based grouping for 3+ tabs from the same site.
- **🔍 Tab Search** — Instantly find any tab by title or URL. Click to jump.
- **🗑️ Duplicate Detection** — One-click close all duplicate tabs.
- **💾 Session Save & Restore** — Save your tab layout and restore it later. Free: 3 sessions. Pro: unlimited.
- **⌨️ Keyboard Shortcuts** — `Ctrl+Shift+A` smart group, `Ctrl+Shift+G` domain group, `Ctrl+Shift+D` close duplicates, `Ctrl+Shift+C` collapse all.
- **📊 Tab Stats** — Track your tab usage over time.

### 💰 Pricing

- **Free** — Domain grouping, search, duplicate detection, 3 saved sessions
- **Pro ($3.99 one-time)** — Smart AI grouping, unlimited sessions, tab stats, custom categories

### 🔒 Privacy

All data stays on your device. No telemetry, no tracking, no cloud uploads. Your tabs are your business.

### 💰 价格
