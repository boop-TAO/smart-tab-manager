# 🧠 Smart Tab Manager

> AI-powered Chrome extension for automatic tab grouping and session management

## Features

- 📦 **Auto-Group** — Groups tabs by domain with 3+ open tabs
- 💾 **Save Sessions** — Save and restore tab sessions
- 📁 **Collapse All** — One-click collapse all tab groups
- 🔓 **Ungroup** — Quick ungroup when needed
- 🎨 **Color Coding** — Each domain gets a unique color
- ⚡ **Lightweight** — No external dependencies, pure Chrome API

## Install

1. Clone this repo
2. Go to `chrome://extensions`
3. Enable "Developer mode"
4. Click "Load unpacked" and select this folder

Or install from [Chrome Web Store](#) (coming soon)

## Tech

- Manifest V3
- Chrome Tabs & TabGroups API
- Service Worker
- Vanilla JS, no framework
